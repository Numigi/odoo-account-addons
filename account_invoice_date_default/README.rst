============================
Account Invoice Date Default
============================
This module sets the invoice date to today's date when creating vendor bills.

Usage
-----
As an Accounting / Invoicing user:

- I create a vendor bill from the accounting,
- I notice that the “Invoice date” (invoice_date) is filled in automatically and it is equal by default to the current date.
- I am able to change it if it does not match the desired date.

.. image:: https://raw.githubusercontent.com/Numigi/odoo-account-addons/14.0/account_invoice_date_default/static/description/vendor_bill_default_date.png

Notice
------
Even if the vendor bill is created from a purchase order, the invoice date will be set to today's date.
